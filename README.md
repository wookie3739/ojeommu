# 점심 메뉴 투표 앱 (Lunch Vote App)

팀원들과 함께 점심 메뉴를 쉽게 결정할 수 있는 투표 애플리케이션입니다.

## 기능

- 식당 목록 보기
- 식당 검색 및 필터링
- 랜덤 식당 추천
- 식당별 투표 기능
- 투표 결과 실시간 확인
- 오늘의 점심 우승 후보 표시

## 설치 및 실행

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 프로덕션 서버 실행
npm run start
```

## 배포

이 프로젝트는 Vercel에 배포할 수 있습니다:

1. GitHub에 프로젝트를 푸시합니다
2. Vercel 계정을 생성합니다 (https://vercel.com)
3. New Project를 클릭하고 GitHub 저장소를 선택합니다
4. 기본 설정을 유지하고 Deploy 버튼을 클릭합니다

## 기술 스택

- Next.js
- React
- TypeScript
- CSS
- Vercel (배포)
