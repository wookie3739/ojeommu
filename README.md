# 점심 메뉴 투표 앱 (Lunch Vote App)

팀원들과 함께 점심 메뉴를 쉽게 결정할 수 있는 투표 애플리케이션입니다.

## 주요 기능

- 식당 목록 조회 및 검색
- 카테고리 및 가격별 필터링
- 랜덤 식당 추천
- 식당별 투표 기능
- 투표 결과 실시간 확인
- 오늘의 점심 우승 후보 표시

## 기술 스택

- Next.js
- React
- TypeScript
- CSS
- localStorage (투표 데이터 저장)

## 특징

- 서버리스 구조: API 없이 클라이언트 사이드에서만 작동합니다
- 날짜별 투표 관리: 하루에 한 번만 투표할 수 있으며, 날짜가 바뀌면 투표가 초기화됩니다
- 반응형 디자인: 모바일과 데스크톱 환경 모두 지원합니다

## 사용 방법

1. 웹사이트에 접속합니다
2. 원하는 식당을 필터링하거나 검색합니다
3. 식당을 선택하여 상세 정보를 확인합니다
4. 마음에 드는 식당에 투표합니다
5. 가장 많은 표를 받은 식당이 우승 후보로 선정됩니다

## 로컬에서 실행하기

```bash
# 의존성 설치
npm install

# 개발 서버 실행
npm run dev

# 프로덕션 빌드
npm run build

# 빌드된 앱 실행
npm start
```
